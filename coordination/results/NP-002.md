## 4. Decisiones y límites conocidos

- **Configuración fuera del bundle:** `js/public-config.js` se mantiene como script separado previo a `js/bundle.js` para que cada instalación pueda declarar su modo sin recompilar ni duplicar literales.
- **Números telefónicos sintéticos:** los valores `1100000001`, `1100000002` y `5491100000000` se utilizan exclusivamente con mensajería simulada/bloqueada; no se afirma verificación regulatoria sobre la asignación real de esa numeración.
- **Alcance de seguridad:** el PIN local de interfaz (`staffPin`) sigue siendo un control operativo de UI en este tramo; la autenticación real con Supabase Auth + RLS, las transacciones idempotentes y el outbox de WhatsApp corresponden a los paquetes posteriores (`NP-004` a `NP-009`).
