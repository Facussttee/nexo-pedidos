# Nexo Pedidos

Una instalación por comercio, mismo código configurable. Pilotos previstos: unitario, pesable y mixto.
Conservar catálogo/carrito/preparación móvil y diferencia entre estimado y final.
Primer checkpoint limitado a base independiente, E0 documental, demo sintética aislada y servidor estático confinado.
Después: Auth/RLS, transacciones e idempotencia, inventario/reservas, perfil configurable, entrega/pago separados y outbox WhatsApp.
Fuera del arranque: SaaS multicliente, fiscal, lotes, vencimientos, múltiples depósitos, IA conversacional y despliegue productivo.
Estado inicial: código heredado, no validado como producto seguro. No promete stock cuantitativo, offline transaccional o entrega de mensajes exactamente una vez.
